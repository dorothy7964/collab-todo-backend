# 🗃️ Category 모듈

- 그룹 내 할 일을 분류하기 위한 카테고리 관리
- 장보기, 청소, 기타 등 그룹별 카테고리 생성 및 관리
- 할 일(Todo)을 카테고리별로 구분
- 그룹에 종속된 하위 작업 공간

<br/><br/>

## 🗃️ 카테고리 구조

- Category는 특정 Group에 소속된다.
- 하나의 Group은 여러 개의 Category를 가질 수 있다.
- 하나의 Category는 여러 개의 Todo를 가질 수 있다.

```text
Group
 ├── Category
 │    ├── Todo
 │    ├── Todo
 │    └── Todo
 │
 ├── Category
 │    ├── Todo
 │    └── Todo
 │
 └── Category
      └── Todo
```

<br/><br/>

## 🗑️ 삭제 정책

### Group — Soft Delete

- 기존 데이터를 삭제하지 않고 `deletedAt`을 기록
- 삭제된 그룹의 데이터 유지
- 필요할 경우 `restoreGroup()`을 통해 복구

### Category — Hard Delete

- 카테고리를 데이터베이스에서 완전히 삭제
- 별도의 카테고리 복구 기능은 제공하지 않음
- 카테고리 삭제 시 연결된 Todo 데이터는 유지
- Todo의 `category` 연결은 `NULL`로 변경

### Todo — 데이터 유지

- 카테고리 삭제 시 Todo 자체는 삭제하지 않음
- 카테고리와의 관계만 해제
- 카테고리 없이도 Todo 데이터를 유지할 수 있도록 설계

```text
카테고리 삭제 전
Category
 └── Todo
      └── categoryId: 20

          ↓ Hard Delete

카테고리 삭제 후
Category: 삭제됨

Todo
 └── categoryId: NULL
      └── Todo 데이터 유지
```

- Todo와 Category의 관계에 `nullable: true` 설정
- 외래 키 삭제 정책에 `onDelete: 'SET NULL'` 적용

## 구현 기능

### ➕ 카테고리 생성 (`createCategory`)

- ✅ 카테고리 이름 생성
- ✅ 카테고리 아이콘 설정
- ✅ 카테고리 색상 설정
- ✅ 그룹 소속 여부 확인
- ⬜ 그룹 멤버 권한 확인 (현재: 그룹 멤버면 생성 가능)
- ✅ 중복 카테고리 이름 확인
- ✅ 카테고리 생성 완료

<br/>

### ✏️ 카테고리 수정 (`updateCategory`)

- ✅ 카테고리 이름 수정
- ✅ 카테고리 아이콘 수정
- ✅ 카테고리 색상 수정
- ✅ 카테고리 순서 변경
- ✅ 그룹 멤버 권한 확인
- ✅ 카테고리 수정 완료

<br/>

### 📄 카테고리 상세 조회 (`category`)

- ✅ 카테고리 기본 정보 조회
- ✅ 카테고리 소속 그룹 확인
- ✅ 그룹 멤버 여부 확인
- ⬜ 카테고리의 할 일 목록 조회
- ⬜ 전체 할 일 개수 조회
- ⬜ 완료된 할 일 개수 조회
- ⬜ 카테고리 진행률 조회

<br/>

### 🗑️ 카테고리 삭제 (`deleteCategory`)

- ✅ 카테고리 존재 여부 확인
- ✅ 그룹 소속 여부 확인
- ✅ 그룹장만 삭제 권한 부여
- ⬜ 카테고리 Hard Delete
- ⬜ 연결된 Todo의 카테고리 관계 해제 (`NULL`)
- ⬜ Todo 데이터 유지 확인
- ⬜ 카테고리 삭제 완료

<br/>

### 📋 카테고리 목록 조회 (`getCategories`)

- ✅ 그룹별 카테고리 조회
- ⬜ 카테고리별 할 일 개수 조회
- ⬜ 카테고리별 완료된 할 일 개수 조회
- ⬜ 카테고리별 진행률 조회
- ⬜ 카테고리 정렬 순서 적용

## ⭐ 기본 카테고리

그룹 생성 시 기본 카테고리를 생성할 수 있다.

예시:

- 🛒 장보기
- 🧹 청소
- 📦 기타

```text
그룹 생성
    ↓
기본 카테고리 생성
    ├── 장보기
    ├── 청소
    └── 기타
```

- ⬜ 그룹 생성 시 기본 카테고리 자동 생성
- ⬜ 기본 카테고리 이름 설정
- ⬜ 기본 카테고리 아이콘 설정
- ⬜ 기본 카테고리 순서 설정

<br/><br/>

## 📊 카테고리 진행률 (추후 예정)

카테고리별 Todo 완료 상태를 기준으로 진행률을 계산한다.

```text
전체 Todo = 5
완료 Todo = 3

진행률 = 3 / 5 × 100
      = 60%
```

스케치 예시:

```text
장보기     3 / 7 완료  ███████░░░
청소       1 / 5 완료  ██░░░░░░░░
기타       0 / 3 완료  ░░░░░░░░░░
```

- ⬜ 전체 Todo 개수 조회
- ⬜ 완료 Todo 개수 조회
- ⬜ 진행률 계산
- ⬜ 그룹 화면에서 카테고리별 진행률 표시

<br/><br/>
