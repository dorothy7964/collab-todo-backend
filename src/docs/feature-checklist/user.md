# 👤 User 모듈

- 이메일 → 고유 식별 및 로그인/검색/초대
- 닉네임 → 화면 표시용 및 변경 가능

<br/><br/>

## 구현 기능

### 📝 회원가입 (`createAccount`)

- ✅ 이메일 중복 검사
- ✅ 비밀번호 암호화(bcrypt)
- ✅ 기본 프로필 이미지 적용
  - [Entity] 기본 이미지가 저장되므로 profileImage를 필수(String)로 유지\_user.entity.ts
  - [DTO] 회원가입 시 이미지를 선택적으로 받을 수 있도록 nullable: true로 처리\_create-account.dto.ts
  - 목적: 이미지를 보내지 않으면 DB의 기본 프로필 이미지가 자동 저장되도록 구현

- ⏸️ 이메일 인증 코드 생성
- ⏸️ 인증 메일 발송

### 🔑 로그인 (`login`)

- ✅ 이메일 존재 여부 확인
- ✅ 비밀번호 검증
- ✅ JWT Access Token 발급

### 👤 내 정보 조회 (`me`)

- ✅ 로그인 사용자 정보 조회
- ✅ AuthGuard 적용

### 🔍 사용자 정보 조회 (`userProfile`)

- ✅ 사용자 조회
- ✅ AuthGuard 적용
- ✅ 예외 처리

### ✏️ 회원 정보 수정 (`updateProfile`)

- ✅ 비밀번호 수정
- ✅ 닉네임 수정
- ✅ 프로필 이미지 수정

### 🔎 사용자 조회 (userLookup)

- ✅ 이메일로 사용자 검색
- ✅ 조회 결과 유저 반환
- ✅ 사용자를 찾을 수 없을 경우 예외 처리

### 📧 이메일 인증 (`verifyEmail`)

> **상태:** ⏸️ 보류

> **사유:** 이메일 인증 유료화로 인한 보류

- ⏸️ 인증 코드 검증
- ⏸️ 이메일 인증 완료
- ⏸️ 인증 코드 삭제

### 👤 회원 탈퇴 (`deleteAccount`)

> **상태:** ⏸️ 게시물 기능 구현 후 진행하기

- ⬜ 로그인 사용자 확인
- ⬜ 비밀번호 검증
- ⬜ 사용자 정보 조회
- ⬜ 회원 탈퇴 처리
- ⬜ 연관 데이터 처리
- ⬜ 탈퇴된 사용자 접근 차단
- ⬜ 탈퇴 성공 응답 반환
