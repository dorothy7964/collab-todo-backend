# 👤 User 모듈

<br/><br/>

## 구현 기능

### 📝 회원가입 (`createAccount`)

- ✅ 이메일 중복 검사
- ✅ 비밀번호 암호화(bcrypt)
- ⬜ 기본 프로필 이미지 적용
- ⏸️ 이메일 인증 코드 생성
- ⏸️ 인증 메일 발송

### 🔑 로그인 (`login`)

- ✅ 이메일 존재 여부 확인
- ✅ 비밀번호 검증
- ✅ JWT Access Token 발급

### 👤 내 정보 조회 (`me`)

- ✅ 로그인 사용자 정보 조회
- ✅ AuthGuard 적용

### 🔍 사용자 정보 조회 (`userProfile`)

- ✅ 사용자 조회
- ✅ AuthGuard 적용
- ⬜ 예외 처리

### 🔎 사용자 검색 (`searchUsers`)

- ⬜ 검색어 기반 사용자 조회
- ⬜ 닉네임 또는 이메일 검색
- ⬜ 검색 결과 반환
- ⬜ 검색 결과가 없을 경우 예외 처리

### ✏️ 회원 정보 수정 (`editProfile`)

- ⬜ 프로필 수정
- ⬜ 이메일 수정
- ⬜ 프로필 이미지 수정

### 📧 이메일 인증 (`verifyEmail`)

> **상태:** ⏸️ 보류

> **사유:** 이메일 인증 유료화로 인한 보류

- ⏸️ 인증 코드 검증
- ⏸️ 이메일 인증 완료
- ⏸️ 인증 코드 삭제
