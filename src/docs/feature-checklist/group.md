# 👥 Group 모듈

- 그룹 생성 및 공동 작업 공간 관리
- 멤버 초대 및 권한 관리
- 카테고리, 할 일, 채팅, 공지의 최상위 공간

<br/><br/>

## 구현 기능

### 👥 그룹 생성 (`createGroup`)

- ✅ 그룹 이름 생성
- ✅ 그룹 대표 이미지 설정
- ✅ 그룹 설명 작성
- ✅ 그룹 생성자를 그룹장(Owner)으로 자동 등록
- ⬜ 기본 카테고리 생성
- ✅ 그룹 생성 완료

### 📋 그룹 목록 조회 (`myGroups`)

- ⬜ 내가 속한 그룹 조회
- ⬜ 그룹 진행률 조회
- ⬜ 멤버 수 조회
- ⬜ 최근 활동 정보 조회

### 📄 그룹 상세 조회 (`group`)

- ⬜ 그룹 기본 정보 조회
- ⬜ 전체 진행률 조회
- ⬜ 멤버 목록 조회
- ⬜ 최근 할 일 조회
- ⬜ 최근 채팅 조회
- ⬜ 공지사항 조회

### ✏️ 그룹 수정 (`editGroup`)

- ⬜ 그룹 이름 수정
- ⬜ 대표 이미지 수정
- ⬜ 그룹 설명 수정
- ⬜ 최대 인원 수정
- ⬜ 그룹 공개 여부 수정

### 🚪 그룹 나가기 (`leaveGroup`)

- ⬜ 그룹 멤버 여부 확인
- ⬜ 그룹 탈퇴
- ⬜ Owner 권한 이전 확인
- ⬜ 마지막 멤버일 경우 그룹 삭제 여부 확인

### 🗑️ 그룹 삭제 (`deleteGroup`)

- ⬜ Owner 권한 확인
- ⬜ 그룹 삭제
- ⬜ 카테고리 삭제
- ⬜ 할 일 삭제
- ⬜ 채팅 삭제
- ⬜ 공지 삭제
- ⬜ 그룹 멤버 삭제

### 📨 그룹 초대 (`inviteGroup`)

- ⬜ 초대 코드 생성
- ⬜ 초대 코드 만료시간 설정
- ⬜ 초대 링크 생성
- ⬜ 그룹 참여
- ⏸️ 초대 코드 생성 (QR 또는 Link)

### 🚫 그룹 멤버 관리 (`removeGroupMember`)

- ⬜ 그룹 멤버 조회
- ⬜ 그룹 멤버 강제 퇴장
- ⬜ Owner/Admin 권한 확인

<br/><br/>

## 추후 구현

### 👑 그룹 권한 관리 (`changeGroupRole`)

- ⬜ Owner 권한 이전
- ⬜ Admin 권한 부여
- ⬜ Admin 권한 해제
- ⬜ Member 권한 관리

### 🔗 초대 코드 고도화 (`groupInvite`)

> 현재는 `Group.inviteCode`를 사용한다.  
> 초대 코드 기능이 확장될 경우 `GroupInvite` 엔티티로 분리하여 관리하는 방안을 고려한다.

- ⬜ 여러 개의 초대 코드 생성
- ⬜ 초대 코드 만료 시간 설정
- ⬜ 초대 코드 사용 횟수 제한
- ⬜ 초대 코드 비활성화
- ⬜ 초대 코드 생성자 관리
