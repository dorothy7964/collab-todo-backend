# 👥 Group 모듈

- 그룹 생성 및 공동 작업 공간 관리
- 멤버 초대 및 권한 관리
- 카테고리, 할 일, 채팅, 공지의 최상위 공간

<br/><br/>

## 그룹 삭제

- Soft Delete : 전제 데이터를 지우지 않고 deletedAt을 기록

<br/><br/>

## 그룹 삭제 / 나가기 분리

- deleteGroup → OWNER → 그룹 자체 삭제
- leaveGroup → MEMBER → 본인만 그룹 탈퇴
- removeGroupMember → OWNER → 다른 MEMBER 강퇴
- OWNER가 그룹을 나가는 경우 OWNER가 바로 나가지 못하게 하고 다른 멤버에게 소유권을 넘긴 후 탈퇴하게 만드는 방식

<br/><br/>

## 구현 기능

### ➕ 그룹 생성 (`createGroup`)

- ✅ 그룹 이름 생성
- ✅ 그룹 대표 이미지 설정
- ✅ 그룹 설명 작성
- ✅ 그룹 생성자를 그룹장(Owner)으로 자동 등록
- ⬜ 기본 카테고리 생성
- ✅ 그룹 생성 완료

### 📋 그룹 목록 조회 (`myGroups`)

- ✅ 내가 속한 그룹 조회
- ⬜ 그룹 진행률 조회
- ⬜ 멤버 수 조회
- ⬜ 최근 활동 정보 조회

### 📄 그룹 상세 조회 (`group`)

- ✅ 그룹 기본 정보 조회
- ⬜ 전체 진행률 조회
- ✅ 멤버 목록 조회
- ⬜ 최근 할 일 조회
- ⬜ 최근 채팅 조회
- ⬜ 공지사항 조회

### ✏️ 그룹 수정 (`updateGroup`)

- ✅ 그룹 이름 수정
- ✅ 대표 이미지 수정
- ✅ 그룹 설명 수정
- ⬜ 최대 인원 수정
- ✅ 그룹 공개 여부 수정

### 🚪 그룹 나가기 (`leaveGroup`)

- ✅ 그룹 멤버 여부 확인
- ✅ 그룹 탈퇴
- ⬜ Owner 권한 이전 확인
  - OWNER가 그룹을 나가는 경우 OWNER가 바로 나가지 못하게 하고 다른 멤버에게 소유권을 넘긴 후 탈퇴하게 만드는 방식
- ⬜ 마지막 멤버일 경우 그룹 삭제 여부 확인

### 🗑️ 그룹 삭제 (`deleteGroup`)

- ✅ Owner 권한 확인
- ✅ 그룹 삭제
- ⬜ 카테고리 삭제
- ⬜ 할 일 삭제
- ⬜ 채팅 삭제
- ⬜ 공지 삭제
- ⬜ 그룹 멤버 삭제
- ⬜ 그룹 삭제 취소 : restore()

### 📨 그룹 초대 (`inviteGroup`)

- ✅ 그룹장이 사용자를 즉시 그룹 멤버로 추가
- ⬜ 초대 코드 생성
- ⬜ 초대 코드 생성
- ⬜ 초대 코드 만료시간 설정
- ⬜ 초대 링크 생성
- ⬜ 그룹 참여
- ⏸️ 초대 코드 생성 (QR 또는 Link)

### 👥 그룹 멤버 관리

- ⬜ 그룹 멤버 조회
- ✅ 그룹 멤버 강제 퇴장(그룹 멤버 내보내기) : removeGroupMember
- ✅ 그룹 멤버 강제 퇴장 및 재가입 차단
- ✅ 그룹 멤버 강제 퇴장 및 재가입 승인
- ⬜ Owner/Admin 권한 확인

- ✅ 멤버 추가
- ✅ 멤버 목록 조회
- ⬜ 멤버 상세 조회
- ⬜ 멤버 삭제
- ⬜ 역할 변경
- ⬜ 그룹장 확인
- ⬜ 가입 승인
- ⬜ 초대
- ⬜ 가입 요청
- ⬜ 멤버 검색

- ⬜ 초대 코드 사용 횟수 제한
- ⬜ 초대 코드 비활성화
- ⬜ 초대 코드 생성자 관리
